1. 개요

  • 인력현황·확보·육성·조직문화·조직건강 등 탭으로 구성된 정적 시안입니다.
  • 선택자는 .hr-dash로 격리합니다.
  • 구현 완료
    • dashboard01.html — 인력현황
    • dashboard02.html — 인력확보 및 유지
  • 준비 중: dashboard03~05.html (작업중 안내)
  • 시안은 각 페이지 JS의 SAMPLE로 렌더링합니다. 운영 시 XFWebService / 패키지 조회로 교체합니다.
  • jQuery / Chart.js / Font Awesome은 신규 추가가 아닙니다. 기존 e-HR 자산·버전과 일치해야 합니다.

6. 기존 시스템 적용 절차

  1. 파일 배치 — HTML / css/ / js/를 서버 정적 경로에 복사
  2. 라이브러리 경로 — ./e-HR_files/... → 운영 기존 경로로 교체
  3. 탭 연결 — DashBoard 탭 src를 본 패키지 URL로 교체 (기본: index.html 또는 dashboard01.html)
  4. 데이터 — 01: HrDashboard.render(data) · 02: HrDashboard02.render(data) ($(function(){...})에서 SAMPLE 대신 실데이터)
  5. 리사이즈 — 각 페이지가 window.resize에서 chart.resize() 호출. iframe 높이 변경 시 resize 이벤트 전달 확인

7. 스타일 · 색상 · 차트 규칙

색상 체계

메인: 블루 계열 베리에이션(Blue 900~200) · 포인트: 01 여 red-400(#f87171) · 02 퇴사율 violet-500(#8b5cf6).

영역톤비고
01 본부·직급 / 02 막대·도넛 Blue 900~200 블루 단색 베리에이션 (진함 → 옅음)
01 재직자 IT/CS Green-500 · Slate-300 IT #22c55e · CS #cbd5e1
01 직책자·성별&연령 / 02 퇴사율 남 blue · 여 red-400 · 퇴사율 violet-500 포인트: 여 레드 / 퇴사율 바이올렛

직급 키(GRADE_ORDER): 임원, 부장, 차장, 과장, 대리, 사원, 계약직(무기)

01 차트 라벨

  • 본부·직급 라벨: 가로 누적(좌→우) · 구간 수치는 막대 안(흰색) · 총계는 막대 끝.
  • 총계: 본부·직급은 막대 끝 · 15px bold. 직책자·성별연령은 항목명 옆 (n) · 15px bold · #333333.
  • IT/CS: IT green-500 · CS slate-300
  • 인력 다양성 배경: .hr-dash__card--diversity에 images/people.png · background-position: 75% 100% · background-size: 25% auto · 3칸 폭 calc(100% - 300px)
  • 직책자 라벨: 본부장 · 법인장 · 담당 · 팀장 · 센터장 · 전문위원 (남 7·1·3·30·0·9 / 여 1·0·3·8·2·0)

02

  • 핵심기술인재·직급/본부 퇴사: 블루 진함→옅음 교대. 퇴사율 포인트 violet-500(#8b5cf6).
  • 2시리즈 막대(신입/경력, 외부/팀원): blue-700 + blue-300 · 비교 막대 간격 0 · 항목 간격 categoryPercentage:0.55.
  • 막대 수치: 15px bold (막대 위).
  • 퇴사 사유 도넛: 그린→라임→틸→스카이 5단 (#22c55e · #84cc16 · #2dd4bf · #38bdf8 · #7dd3fc) · 부적응(lime)과 결혼·육아(teal) 구분 · 최대 360px · 모바일 좌우 배치. 도넛·범례 간격 .hr-dash__reason-wrap gap 16px (모바일 32px).

공통 UI

  • 커스텀 CSS는 .hr-dash 하위로만 작성.
  • 휴직·입사·퇴사 KPI: 아이콘 없음 · 수치만 표시.
  • 제목 보조 .hr-dash__title-sub — 카드 제목 아래 작은 소제목(상하 배치, 괄호 없음). 예) 실시간 기준, 2026년 누적 기준, 직급별 과거 2개년은 12월말 기준, 최신년도는 실시간 기준.
  • 모바일 분기: @media (max-width: 1100px).

8. 적용 체크리스트

  • □ 공통 라이브러리를 신규 추가하지 않고 기존 e-HR 경로로 연결했는가
  • □ jQuery / Chart.js / FA / AdminLTE 버전이 운영과 일치하는가
  • □ FA webfonts 404가 아닌가
  • □ 탭 네비(01 · 02~05) 링크·활성(.on)이 올바른가
  • □ 01: W01~W10 → HrDashboard.render 매핑 완료
  • □ 02: 채용·퇴사 등 → HrDashboard02.render 매핑 완료
  • □ 카드 소제목(.hr-dash__title-sub)이 기준표와 일치하는가
  • □ 01 인력 다양성 배경(images/people.png) 경로가 올바른가
  • □ GRADE_ORDER 직급명(계약직(무기) 포함)이 마스터와 일치하는가
  • □ iframe 높이·리사이즈 후 차트 깨짐이 없는가
  • □ .hr-dash와 글로벌 CSS 충돌이 없는가
