e-HR Dashboard — 적용 가이드

본 문서는 hr_dashboard 시안을 웅진 e-HR(기존 MAINFW / DashBoard)에 이식할 때 개발자가 참조할 적용 가이드입니다.

1. 개요

  • 인력현황·확보·육성·조직문화·조직건강 등 5개 탭으로 구성된 정적 시안입니다.
  • 레이아웃은 EIS 메인 대시보드의 카드/행 패턴을 참고하며, 선택자는 .hr-dash로 격리했습니다.
  • 구현 완료: dashboard01.html(인력현황), dashboard02.html(인력확보 및 유지).
    준비 중: dashboard03~05.html(작업중 안내 화면).
  • 시안은 각 페이지 JS의 SAMPLE 데이터로 렌더링됩니다. 운영 적용 시 XFWebService / 패키지 조회 결과로 교체합니다.
  • jQuery / Chart.js / Font Awesome 등은 새로 추가한 라이브러리가 아닙니다. 기존 e-HR 자산을 연결하며, 운영 서버 버전과 반드시 일치해야 합니다.

폴더 역할
  • dashboard01~05.html / css/ / js/ — 이번 작업에서 신규로 만든 대시보드입니다.
  • e-HR_files/ — 시안 미리보기용 기존 라이브러리 연결입니다. 운영 적용 시 서버에 이미 있는 동일 버전 경로로 src/href를 바꾸어 연결하세요.
중요: 공통 라이브러리는 기존 시스템 자산을 재사용합니다. CDN·신규 패키지로 교체하지 말고, 아래 표 버전과 운영 파일이 일치하는지 확인하세요.

6. 기존 시스템 적용 절차

  1. 신규 파일 배치
    index.html, dashboard01~05.html, css/, js/를 서버 정적 경로에 복사합니다. e-HR_files/는 운영에 동일 버전이 있으면 생략 가능합니다.
  2. 기존 JS/CSS 경로 연결
    각 HTML의 ./e-HR_files/...를 운영 기존 라이브러리 경로로 교체합니다.
  3. 탭 / iframe 연결
    기존 DashBoard 탭 src를 본 패키지 URL로 교체합니다. 기본 진입은 index.html 또는 dashboard01.html.
  4. 데이터 연동
    01: HrDashboard.render(data) · 02: HrDashboard02.render(data). 각 JS의 $(function(){...})에서 SAMPLE 대신 실데이터를 주입합니다.
  5. 리사이즈
    각 페이지가 window.resize에서 chart.resize()를 호출합니다. iframe 높이 변경 시 resize 이벤트 전달을 확인하세요.

7. 스타일 · 색상 · 차트 규칙

  • 커스텀 CSS는 .hr-dash 하위로만 작성.
  • 01 직급 팔레트 (GRADE_PALETTE): Tailwind 400 — blue / orange / slate / amber / sky / emerald / violet.
  • 01 IT/CS·성별: IT sky-400, CS orange-400 / 남 blue-400, 여 red-400. CSS 변수 --hr-dash-it 등과 맞춤.
  • 01 콜아웃 (hrBarCount, calloutStyle:'diagonal'): 본부별·직급별 누적 구간 수치를 대각선으로 밖으로 표시(regular weight). 본부별은 오른쪽 위·숫자 세로 정렬, 직급별은 오른쪽 아래·숫자 가로선 정렬(차트 영역 내 클램프). 직책자·성별&연령대는 막대 안 라벨(어두운 배경이면 흰 글자).
  • 01 직책자 샘플 라벨: 본부장, 실장, 팀장, 파트장 (사장 미포함).
  • 02 팔레트: Tailwind 400 시리즈(SERIES). 퇴직률은 red-400, 직급별 퇴직은 시리즈 랜덤 배정.
  • KPI 아이콘 원: 바이올렛·에메랄드·주황 배경 + 흰 아이콘 20px (원 60px).
  • 제목 보조 문구 .hr-dash__title-sub: 그레이·작은 글자 — 예: (3개년 추이).

8. 적용 체크리스트

  • □ 공통 라이브러리를 신규 추가하지 않고 기존 e-HR 경로로 연결했는가
  • □ jQuery / Chart.js / FA / AdminLTE 버전이 운영과 일치하는가
  • □ FA webfonts 404가 아닌가
  • □ 탭 네비(01~05) 링크·활성(.on)이 올바른가
  • □ 01: W01~W10 → HrDashboard.render 매핑 완료
  • □ 02: 채용·퇴직 등 → HrDashboard02.render 매핑 완료
  • □ GRADE_ORDER 직급명이 마스터와 일치하는가
  • □ iframe 높이·리사이즈 후 차트 깨짐이 없는가
  • □ .hr-dash와 글로벌 CSS 충돌이 없는가
