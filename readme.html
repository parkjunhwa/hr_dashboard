e-HR Dashboard — 적용 가이드

hr_dashboard 시안을 웅진 e-HR(기존 MAINFW / DashBoard)에 이식할 때 보는 적용 가이드입니다. 아래 순서대로 읽으면 파일, 공통 규칙, 화면, 데이터, 식별자, 색, 적용까지 이어집니다.

1. 개요

정적 시안 네 탭입니다. 화면은 각 페이지 JS의 SAMPLE로 그리고, 운영에서는 render(data)에 실데이터를 넣습니다. 스타일은 .hr-dash 안에만 둡니다.

8. 적용 절차

  1. 파일 배치 — HTML, css/, js/를 서버 정적 경로에 복사합니다.
  2. 라이브러리 경로 — ./e-HR_files/...를 운영의 같은 버전 경로로 바꿉니다.
  3. 탭 연결 — DashBoard 탭 src를 이 패키지 주소로 바꿉니다. 기본 진입은 index.html 또는 dashboard01.html입니다.
  4. 데이터 — 각 페이지 $(function(){...})에서 SAMPLE 대신 HrDashboard01~HrDashboard04의 render(data)를 호출합니다. 필드 모양은 5장입니다.
  5. 리사이즈 — 각 페이지는 window.resize에서 chart.resize()를 호출합니다. iframe 높이가 바뀌면 resize 이벤트가 전달되는지 확인합니다.

  • □ jQuery, Chart.js, Font Awesome, AdminLTE 버전이 운영과 같은가
  • □ Font Awesome webfonts가 404가 아닌가
  • □ 탭 01~04 링크와 활성(.on)이 맞는가
  • □ 01: W01~W10이 HrDashboard01.render에 매핑되었는가
  • □ 02·03·04: 각 render 필드가 5장과 맞는가
  • □ 카드 소제목(.hr-dash__title-sub)이 4장과 맞는가
  • □ GRADE_ORDER 직급명에 계약직(무기)가 들어 있는가
  • □ iframe 높이와 리사이즈 뒤에 차트가 유지되는가
  • □ .hr-dash 밖 전역 CSS와 충돌이 없는가
